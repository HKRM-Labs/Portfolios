# Taste Skill (Anti-Slop Frontend Architecture)

## 1. Core Philosophy
AI agents frequently default to generic "AI slop":
- Centered 3-line headlines with zero character
- AI-purple or generic indigo/blue gradients
- Cliché 3-card horizontal feature grids
- Generic rounded pill badges with generic icons
- Lack of negative space intentionality and art direction

**Taste Skill** mandates strict art direction, intentional spacing, bespoke typography pairings, and authentic editorial layout systems.

## 2. The Three Dials Configuration
For high-end fashion and model portfolios:
- **`DESIGN_VARIANCE`**: `8 / 10` (High editorial agency, asymmetric grid structures, bold typographic scale, dynamic overlapping layers)
- **`MOTION_INTENSITY`**: `7 / 10` (Cinematic scroll-driven transitions, buttery smooth easing, magnetic interactions, reveal masks)
- **`VISUAL_DENSITY`**: `3 / 10` (Expansive luxury whitespace, art-gallery breathing room, focalized imagery)

## 3. Mandatory Layout & Aesthetic Rules
1. **Zero Cookie-Cutter Grids**: Never render 3 identical cards in a row. Use masonry lookbooks, 2-column editorial zigs, asymmetric magazine layouts, or full-bleed horizontal reels.
2. **High-Fashion Typographic Pairing**:
   - Editorial Serif for Headings: *Cormorant Garamond*, *Playfair Display*, or *Italian Garamond* (italicised accents, ligatures, high contrast).
   - Modern Grotesque for Utility & Body: *Plus Jakarta Sans*, *Syne*, or *Geist* (clean tracking, uppercase subheadings with `tracking-[0.25em]`).
3. **Curated Luxury Color Palette**:
   - Deep Noir: `#0B0B0B` / `#121212`
   - Alabaster / Chalk: `#F9F8F6` / `#F0EFEA`
   - Champagne Gold / Warm Bronze: `#C5A880` / `#D4AF37`
   - Muted Slate / Charcoal: `#242424` / `#7A7A7A`
4. **Authentic Media Framing**:
   - High-aspect ratio frames (3:4 portrait, 9:16 vertical reels, 16:9 cinematic widescreen).
   - Subtle hover zooms (`scale-105 duration-700 ease-out`), film grain overlays, and soft vignettes.
