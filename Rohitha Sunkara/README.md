# Rohitha Sunkara (Ruhi) • Official Film Acting & Haute Couture Portfolio

A world-class, cinema-grade editorial portfolio and casting platform for **Rohitha Sunkara** (`@hitaa.s`), featuring high-fashion runway motion, 1.8M+ viral reels, and a dedicated **Film Acting Repertoire** highlighting open movie roles across Tollywood and Pan-Indian cinema.

## Visual Direction & Aesthetics
- **Theme**: Luxury White & Radiant Blush Pink with Rose Quartz and Carmine accents.
- **Typography**: Didone & Bodoni Moda, Abril Fatface, Cormorant Garamond, Syne.
- **Kinetic Strips**: 3 bi-directional high-fashion typography marquees.
- **Sticky Runway**: 3:4 motion sequence with Framer Motion inertia.
- **Acting Section**: Dedicated feature film and OTT casting callouts.
- **Social Vault**: 1.8M viral reels with real-time video playback and official QR code.
- **Mobile Responsive**: 100% viewport optimization with zero horizontal overflow.

## Quick Start
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
